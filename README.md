# Internet Speed Test

CLI тулза для проверки скорости интернета. Выполнено в качестве тестового задания для "Это Легко"

## Использование

```bash
python main.py <URL>
```

Указание единицы измерения скорости:
```bash
python main.py <URL> --unit mbps
python main.py <URL> --unit mibps
```
По умолчанию используется `mbps`
